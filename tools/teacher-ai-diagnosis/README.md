# 우리학교 교사 AI 역량 수준 진단: 응답 저장소 연결

페이지: `in-progress/teacher-ai-competency/index.html` · 스크립트: `assets/js/teacher-ai-diagnosis.js` · 저장소: `apps-script.gs`

AI 역량 수준 진단(`in-progress/ai-competency/`)을 그대로 복제하고 다음만 바꿨다. 원본 진단과 응답 시트·저장 키(`tadx-v1`)가 따로라 서로 섞이지 않는다.

- 처음 화면에서 **소속 학교**(직장 이름도 가능)를 적는다. 비우면 다음으로 넘어가지 않는다.
- **우리 그룹 분석결과**는 나와 같은 소속으로 응답한 사람끼리만 계산한다. 띄어쓰기·대소문자·문장부호 차이(`대한 고등학교` = `대한고등학교`)는 같은 소속으로 본다.
- **전체 응답자 분석결과**를 따로 볼 수 있다(소속·그룹 구분 없이 모든 응답).

## 연결 순서 (5분)

1. 개인 Gmail 계정으로 **새** 스프레드시트를 만든다(원본 진단 시트와 따로). 이름 예: `우리학교 교사 AI 역량 진단 응답`.
2. **확장 프로그램 → Apps Script**를 열고, 기본 코드를 지운 뒤 `apps-script.gs` 내용을 붙여 넣고 저장한다.
3. **배포 → 새 배포 → 유형: 웹 앱**, 실행 계정 **나**, 액세스 권한 **모든 사용자**.
4. 권한을 승인하고 나오는 웹 앱 URL을 `in-progress/teacher-ai-competency/index.html` 머리말 `endpoint`에 넣는다.

응답은 `responses` 시트에 한 줄씩 쌓인다(제출 시각, 결과 코드, 그룹, 구분, 응답 시간(초), 31문항, 소속).

## 알아 둘 점

- 웹 앱은 소속 이름을 내보내지 않는다. 같은 소속 이름을 보낸 사람에게만 그 소속의 응답(구분과 31개 응답값)을 돌려준다.
- 인원이 적은 소속은 응답자가 드러날 수 있다. 그룹 내 위치(상위 몇 %)는 비교 응답이 5명 이상일 때부터 보인다(`MIN_N`).
- Apps Script 코드를 고친 뒤에는 **배포 관리 → 수정 → 버전: 새 버전**으로 다시 배포해야 반영된다(URL은 그대로). "새 배포"를 누르면 URL이 바뀐다.
