# AI 역량 수준 진단: 응답 저장소 연결

페이지: `in-progress/ai-competency/index.html` · 스크립트: `assets/js/ai-diagnosis.js`

페이지 머리말의 `endpoint`가 비어 있으면 **시험 모드**로 동작한다. 응답은 응답자 브라우저(localStorage)에만 저장되고, 그 브라우저의 응답끼리만 분석한다(가상 응답 없음). 실제로 응답을 모으려면 아래처럼 Google 스프레드시트를 연결한다. 시험 모드에서 남긴 응답은 실제 수집과 섞이지 않는다(저장 키가 다르다).

## 연결 순서 (5분)

1. 개인 Gmail 계정으로 새 스프레드시트를 만든다. 학교(Workspace) 계정은 관리자 설정 때문에 "모든 사용자" 공개 배포가 막혀 있을 수 있다. 이름 예: `AI 역량 진단 응답`.
2. 메뉴 **확장 프로그램 → Apps Script**를 연다. 기본 코드를 지우고 `apps-script.gs` 내용을 붙여 넣고 저장한다.
3. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
4. 권한을 승인하고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사한다.
5. `in-progress/ai-competency/index.html` 머리말에 넣는다.
   ```yaml
   endpoint: "https://script.google.com/macros/s/…/exec"
   ```

응답은 스프레드시트의 `responses` 시트에 한 줄씩 쌓인다(제출 시각, 결과 코드, 그룹, 구분, 응답 시간(초), 31문항).

## 그룹별로 받기

링크 뒤에 `?group=코드`를 붙이면 그 링크로 들어온 응답은 같은 그룹으로 묶이고, "우리 그룹 분석결과"도 그 그룹만 계산한다.

- 예: `https://hrdpro.hanyang.ac.kr/in-progress/ai-competency/?group=HRD2026`
- 그룹 코드는 영문·숫자·한글·`-`·`_`, 40자 이내.
- `?group` 없이 들어오면 전체 응답을 기준으로 비교한다.

## 데이터 초기화

- 시험 응답을 지우려면 `responses` 시트의 2행부터 아래를 삭제한다(1행 머리글은 남긴다).
- 응답자 브라우저에 남은 내 결과까지 무효로 하려면 `ai-diagnosis.js`의 저장 키 판(`aidx-v2`)을 `aidx-v3`처럼 올린다.

## 알아 둘 점

- 웹 앱은 그룹 응답 목록을 누구에게나 돌려준다(결과 코드는 빠지고, 구분과 31개 응답값만). 이름·이메일은 묻지 않는다.
- Apps Script 코드를 고친 뒤에는 **배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영된다(URL은 그대로).
- 그룹 내 위치(상위 몇 %)는 비교 응답이 5명 이상일 때부터 보인다(`MIN_N`).
- 유형 구분과 정착 기준점 60점은 타당화 전의 잠정 기준이다. 자료가 모이면 `ai-diagnosis.js`의 `typeOf`, `CUT`을 조정한다.
