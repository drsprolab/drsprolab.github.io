# Appointment request 메일 백엔드

GitHub Pages는 정적 사이트이므로 메일 전송과 승인 처리는 Google Apps Script 웹 앱에서 실행합니다.

1. 확정 메일을 발송할 Google 계정으로 [script.google.com](https://script.google.com/)에서 새 프로젝트를 만듭니다. 현재 배포는 **psu.jihoonsong@gmail.com** 계정으로 실행하고, 요청 메일은 **jhsong77@hanyang.ac.kr**로 보냅니다.
2. 이 폴더의 `Code.gs` 전체를 스크립트 편집기에 붙여 넣습니다. 프로젝트 설정에서 `appsscript.json` 표시를 켜고 파일 내용도 복사합니다. 기존 배포는 새 버전으로 업데이트합니다.
3. **프로젝트 설정 → 스크립트 속성**에 `ADMIN_PASSWORD`를 추가하고 열람 비밀번호를 입력합니다. 첫 로그인 때 솔트와 SHA-256 해시로 바뀌고 원문 속성은 삭제됩니다. 변경할 때는 `ADMIN_PASSWORD`를 다시 추가합니다.
4. **배포 관리 → 기존 배포 편집 → 새 버전**으로 배포합니다. 새 프로젝트라면 **배포 → 새 배포 → 웹 앱**에서 '실행 계정: 나', '액세스 권한: 모든 사용자'를 선택합니다. Google이 요구하는 메일·시트·Drive 권한을 승인합니다.
5. 배포된 **/exec URL**을 `_config.yml`의 `appointment_script_url`에 입력한 뒤 사이트를 빌드·배포합니다.
6. 실제 이메일 2개로 요청 → 교수님 메일 수신 → 승인 링크 클릭 → 학생 확정 메일 수신 및 Google 캘린더 일정 생성을 확인합니다. `/appointment/admin/`에서 로그인 후 확정 목록과 PDF 다운로드를 점검합니다.

첫 요청 시 해당 Google 계정 드라이브에 요청 기록용 스프레드시트가 자동 생성됩니다. 승인 링크는 무작위 토큰으로 보호되며, 링크를 여는 것만으로 승인되지는 않습니다. 이미 캘린더에 일정이 있는 시간은 요청·승인할 수 없고, 승인되면 Apps Script 실행 계정의 기본 Google 캘린더에 1시간 일정이 생성됩니다. 이 Google 계정의 캘린더가 macOS 캘린더에 동기화되어 있으면 맥 캘린더에도 자동 표시됩니다. PDF만 드래그 앤 드롭으로 첨부할 수 있으며, 최대 3개, 합계 4MB까지 요청 메일에 첨부됩니다. 연구 관련 미팅은 첨부파일이 필수입니다.

대문 안내의 이메일 링크로 들어온 진학문의·컨설팅 문의는 월–금 13:00–18:00 사이 1시간 단위로 신청합니다. 기존 일반·연구 미팅은 월·화·목 13:00–15:00 설정을 유지합니다. 진학문의·컨설팅 문의를 승인하면 지정된 인사말·일시·504호 방문 안내를 신청자에게 자동 발송합니다.

PDF 첨부파일은 첫 첨부 요청 때 생성되는 비공개 Drive 폴더에 저장합니다. 관리자 화면에서는 확정된 미팅의 파일만 받을 수 있습니다. 이전에 이메일로만 받은 첨부파일은 소급 표시되지 않습니다. 비밀번호 실패 5회 시 15분, 하루 20회 시 24시간 잠깁니다.
